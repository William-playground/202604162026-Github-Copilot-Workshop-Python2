# アーキテクチャ概要

## 全体構成

シンプルなFlaskベースのWebアプリケーションです。バックエンドとフロントエンドが単一リポジトリにまとまっています。

```
1.pomodoro/
├── app.py               # Flaskアプリ本体（ルーティング・ビジネスロジック）
├── templates/
│   └── index.html       # メインHTMLテンプレート（Jinja2）
└── static/
    ├── css/
    │   └── style.css    # スタイルシート
    └── js/
        └── timer.js     # フロントエンドタイマーロジック
```

## バックエンド

- **フレームワーク**: Flask
- **エントリポイント**: `app.py`
- **データストア**: インメモリ（Pythonの辞書型変数 `progress`）。永続化なし。
- **日付リセット**: APIアクセスのたびに `_reset_if_new_day()` が呼ばれ、日付が変わっていればカウントをリセットします。

### 主要コンポーネント

| コンポーネント | 説明 |
|---|---|
| `progress` | 当日の進捗データを保持するインメモリ辞書 |
| `_reset_if_new_day()` | 日付変更検知とリセット処理 |
| `GET /api/progress` | 進捗取得エンドポイント |
| `POST /api/progress` | 進捗記録エンドポイント |
| `GET /` | フロントエンドHTML配信 |

## フロントエンド

- **構成**: バニラJavaScript（フレームワークなし）
- **即時実行関数（IIFE）**: `timer.js` はスコープ汚染を防ぐため全体をIIFEで包んでいます。
- **タイマー制御**: `setInterval` によるカウントダウン
- **API通信**: Fetch API を使用してバックエンドと通信

## データフロー

```
ユーザー操作（開始/一時停止/リセット）
        ↓
    timer.js（タイマーカウントダウン）
        ↓（タイマー完了時）
POST /api/progress → app.py（進捗を記録）
        ↓（レスポンス）
timer.js（UI上の統計情報を更新）
```

## 制約・注意事項

- データはインメモリのため、**サーバー再起動で消去**されます。
- 複数ユーザーが同一サーバーにアクセスする場合、**進捗データは共有**されます（ユーザー分離なし）。
- 起動コマンド: `python app.py`（デバッグモード、ポート5000）
