# API リファレンス

## 概要

ポモドーロタイマーアプリのREST APIです。進捗データの取得と記録を行います。データはサーバーのメモリに保持されており、日付が変わると自動的にリセットされます。

ベースURL: `http://localhost:5000`

---

## エンドポイント一覧

### GET /api/progress

今日の進捗データを取得します。

**リクエスト**

```
GET /api/progress
```

**レスポンス**

| フィールド | 型 | 説明 |
|---|---|---|
| `count` | integer | 今日完了したポモドーロ数 |
| `totalMinutes` | integer | 今日の合計集中時間（分） |

**レスポンス例**

```json
{
  "count": 3,
  "totalMinutes": 75
}
```

**ステータスコード**

| コード | 説明 |
|---|---|
| 200 | 成功 |

---

### POST /api/progress

ポモドーロ完了時に進捗を記録します。

**リクエスト**

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| `minutes` | number | 任意 | 集中した時間（分）。省略時は25分。1〜60の範囲外または無効な値の場合は25分として処理されます。 |

**リクエスト例**

```json
{
  "minutes": 25
}
```

**レスポンス**

記録後の最新の進捗データを返します。

| フィールド | 型 | 説明 |
|---|---|---|
| `count` | integer | 今日完了したポモドーロ数（更新後） |
| `totalMinutes` | integer | 今日の合計集中時間（分）（更新後） |

**レスポンス例**

```json
{
  "count": 4,
  "totalMinutes": 100
}
```

**ステータスコード**

| コード | 説明 |
|---|---|
| 200 | 成功 |

---

## その他のルート

### GET /

メインページ（`index.html`）を返します。

---

## バリデーションルール

- `minutes` の値が `int` または `float` でない場合、25分に補正されます。
- `minutes` が 0 以下または 60 より大きい場合、25分に補正されます。
